    How It Works

    🖼

    Preprocessing

    Images are resized to 128×128 and enhanced via CLAHE illumination normalisation + Gaussian denoising.

    📐

    Feature Extraction

    58 handcrafted features extracted — 12 colour (RGB + HSV), 20 GLCM texture (4 angles), 26 LBP histogram bins.

    🤖

    ML Classification

    7 traditional ML models trained (SVM, Random Forest, KNN, Decision Tree, Logistic Regression, Naive Bayes, XGBoost). Best model selected by 5-fold CV.

    📊

    No Deep Learning

    Built entirely with Scikit-learn and XGBoost. No CNN, no PyTorch, no TensorFlow — pure traditional ML for academic clarity.
